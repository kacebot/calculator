# Calculator

Máy tính web đơn giản, chạy hoàn toàn phía client — không cần server, không cần build.

## Tính năng

- Cộng, trừ, nhân, chia, phần trăm (%), đổi dấu (+/−)
- Hỗ trợ nhập từ bàn phím (số, `+ - * /`, `Enter` để tính, `Esc` để xóa, `Backspace`)
- Hiển thị biểu thức đang tính, xử lý chia cho 0 (báo Lỗi)
- Giao diện responsive, dùng tốt trên điện thoại

## Chạy local

Mở file `index.html` bằng trình duyệt là dùng được ngay.

## Deploy

Deploy tĩnh lên Cloudflare Pages từ thư mục này.
